Ben's Website Style Guide

  • Header

    The color for my headers are a dark red and bolded. I also added a background with darker gray to make the header stand out. It's font size is x-large.

  • General

    The color for general text is black, with a font size of 18px..

  • Navlinks

    The color for hyperlinks is indigo, with a font size of 18px..

  • Imagetitle

    The color for title/captions on images is black and bolded, with a font size of 18px.

  • Authors

    The color of text for authors names is gray, with a font size of 18px.

  • Quote

    The color for quotes is black, with a font-style of italic, and a font size of 18px.

  • Source

    The color for source links is a light blue, with a font size of 18px.

  • Comments

    The color for comments is a shade of orange, with a font size of 18px

  • Ratings

    The color for ratings is olive green, with a font size of 18px. It is also semi-bolded.

  • Genre

    The color for genre tags is purple, with a font size of 18px.

  • List Style

    The list items have a square style (to seperate other lists from bullet point lists).
